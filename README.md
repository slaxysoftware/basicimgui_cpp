# basicimgui_cpp

Modern, lightweight C++ ImGui framework and UI with custom loader and menu styling.

![krx imgui](krx%20imgui.png)

## Features
- Custom styled ImGui components & dark theme
- Built-in animated loader & transition system
- Interactive keybind system with indicators
- Profile config manager
- Direct3D 11 backend

## Build
Open `krxbasicimgui.sln` with Visual Studio 2022 and build `Release | x64`.
